# La Cazotte — Mes documents

Prototype statique d'un portail de dépôt et de suivi des documents administratifs, conçu pour être publié sur GitHub Pages.

## Publication sur GitHub Pages

1. Créez un nouveau dépôt GitHub.
2. Ajoutez à la racine du dépôt `index.html`, `styles.css`, `app.js` et `.nojekyll`.
3. Dans GitHub, ouvrez **Settings → Pages**.
4. Choisissez **Deploy from a branch**, la branche `main`, puis le dossier `/ (root)`.
5. Enregistrez. GitHub affichera ensuite l'adresse publique du site.

## Important avant une utilisation réelle

Cette version est une démonstration visuelle : les fichiers sélectionnés ne sont jamais envoyés ni conservés. GitHub Pages héberge uniquement des sites statiques et ne suffit pas pour stocker des documents administratifs confidentiels.

Une version de production doit ajouter un serveur sécurisé, une authentification, une base de données, un stockage privé, des droits d'accès, un journal d'activité, des sauvegardes et une politique RGPD. Ne jamais ajouter de véritables documents administratifs dans le dépôt GitHub.

## Personnalisation rapide

- Les couleurs sont définies au début de `styles.css`.
- Les documents de démonstration sont définis au début de `app.js`.
- Les textes et rubriques principales se trouvent dans `index.html`.
